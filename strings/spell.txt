:red_tape:
	:name:
		Red Tape

	:documentation:
		1.

		If a valid word is spelled in the word builder, and it is a slur, swear, the word “{special_word}”, or a word that has been submitted previously this run, see Section 1.1.

		Otherwise, see Section 2.

		1.1.

		If the spelled word is a slur, convert each tile in the word builder to tarnished, then submit without ending your turn or gaining spell charges.

		Otherwise, if the spelled word is a swear, convert each tile in the word builder to money.

		Otherwise, if the spelled word is “{special_word}”, submit the spelled word, then see Section 1.2.

		Otherwise, if the spelled word was submitted previously, if repeat words are allowed, randomly shuffle the faces of all tiles in the word builder. If repeat words are disallowed, see Section 1.3.

		1.2.

		If this spell has more than 3 maximum charges, set its maximum charge to 2 and fully drain its charge.

		Otherwise, set its maximum charge to 4 and fully recharge it.

		1.3.

		Submit the spelled word.

		Unless the repeated word was part of a shimmering permutation, fully drain this spell’s charge.

		2.

		Select a tile.

		If the tile is in the first row, see Section 2.1.

		Otherwise, if the tile is shimmering, see Section 2.2.

		Otherwise, if the tile has a harmful status, see Section 2.3.

		Otherwise, if a valid single word is spelled in the word builder, and the tile is not in the word, see Section 2.4.

		Otherwise, see Section 3.

		2.1.

		If the first row forms one or more valid words, submit them without ending your turn or gaining spell charges.

		Otherwise, shift the faces of every tile in the selected tile’s column down by 1, wrapping around at the bottom of the board.

		2.2.

		If every face of the tile is a single letter, convert all faces to the corresponding number.

		Otherwise, if the tile is not a bomb, convert the tile to a bomb.

		Otherwise, explode the tile.

		2.3.

		If the face is slashed, convert the face to two random slashed numbers.

		If the face is a unigram, see Section 2.3a.

		If the face is a bigram, see Section 2.3b.

		If the face is a trigram, see Section 2.3c.

		Otherwise, waste a charge.

		2.3a.

		If the face is a letter with a value greater than 1, set the face to a random letter with a value 1 lower.

		Otherwise, if the face is a letter, set the face to a random number.

		Otherwise, if the face is “*”, set the face to “null”.

		Otherwise, set the face to “*”.

		2.3b.

		If the face contains any suits, randomize it to a similar face.

		Otherwise, insert a slash between the two characters.

		2.3c.

		If you have been deliberating for an even number of seconds, remove the last character from the face.

		Otherwise, remove the first character from the face.

		2.4.

		If the spelled word is 3 or less letters long, set the face to the spelled word.

		Otherwise, if the face is a single letter, shift its letter through the alphabet by the length of the spelled word.

		Otherwise, if the face is comprised entirely of wildcards, convert the tile to eternal.

		Otherwise, randomize the face to a similar face.

		3.

		If the tile is wooden, see Section 3.1.

		If the tile is plastic, see Section 3.2.

		3.1

		If there are no plastic tiles, convert the tile to plastic.

		Otherwise, if the total value of all plastic tiles is less than 3, swap the face of the tile with a random plastic tile.

		Otherwise, if the tile neighbors any plastic tiles, remove all neighboring plastic tiles.

		Otherwise, if the board contains no crits, see Section 3.1a.

		Otherwise, convert the tile to ivory.

		3.1a.

		If you can find crits naturally, and your current crit chance is 10% or higher, convert the tile to a crit.

		Otherwise, if the board contains no bombs, convert the tile to a bomb with a 1-3 turn fuse.

		Otherwise, waste a charge.

		3.2

		If the tile has any status, clear it and all adjacent tile’s statuses.

		Otherwise, if your current health is a prime number, convert the tile to a crit.

		Otherwise, if your current health is below or equal to 50% of your maximum health, convert the tile to candy.

		Otherwise, if the tile is the only plastic tile on the board, convert it to concrete.

		Otherwise, convert it to wood.

		Beat the game on Red Clearance in a non-daily run.
